# Atlas structure and page template

## Layout (adapt to the industry; drop folders that do not apply, add ones that do)

```
industries/<slug>/
  config.yaml  ontology.yaml
  databases/*.jsonl          # the source of truth (claims, sources, companies, ...)
  staging/                   # agent batches waiting to merge; _merged/ keeps history
  logs/merges.jsonl          # per-batch counts (feeds saturation)
  phase0/                    # discovery notes, ontology rationale, maps
  atlas/
    README.md                # start here: reading order for a beginner
    00-overview/             # executive overview, research log, stop rationale, methodology notes
    01-definition/  02-history/  03-market-structure/  04-value-chain/
    05-participants/  06-business-models/  07-economics/  08-workflows/
    09-regulation/  10-technology/  11-companies/  12-startups/  13-capital/
    14-competition/  15-dynamics/  16-problems/  17-opportunities/  18-risks/
    19-interview-guides/  20-glossary/  21-open-questions/  22-contradictions/
    databases/               # GENERATED by `irs build`; never edit
```

Folders 20–23 largely point to generated database pages; the narrative folders hold synthesized pages.

## Narrative page template (every major section)

```markdown
# <Topic>

> Scope: <what this page covers>. Period: <as-of date / historical range>. Geography: <...>.
> Built from research units: RU-0012, RU-0013. Last synthesized: YYYY-MM-DD.

## What this means
Plain-language explanation for someone new to the industry. Define every term on first use
(and make sure it is in the glossary).

## Why it matters
Its significance for how the industry works.

## How it works
The actual mechanism: steps, actors, flows. Use diagrams (mermaid) where they help.

## Evidence
The supporting facts, each cited inline as [CLM-0042]. Tables of metrics must keep unit, period
and geography columns. Show confidence where it is not high.

## What we still don't know
Unknown claims, open contradictions, interview questions (link INT- ids).
```

## Citation rule

Cite claims, not URLs: `[CLM-0042]`. The claims ledger links each claim to its sources, evidence, status and confidence. `irs validate` rejects citations to missing or failed claims and warns about any paragraph with figures but no citation. Inferences are allowed in narrative only when they are recorded as `inference` claims and cited.
