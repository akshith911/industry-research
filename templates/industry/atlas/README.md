# {{INDUSTRY_NAME}}: Industry Knowledge Atlas

Status: Phase 0 (research architecture). Nothing here is a conclusion yet.

**How to read this atlas.** Start with `00-overview/`, then follow the numbered folders. Every figure cites a claim id like `CLM-0042`; open `databases/claims.md` to see its source, the exact supporting passage, its status and its confidence. Confidence is computed from evidence quality, never guessed:

| Confidence | Meaning |
|---|---|
| high | independently verified against a primary (tier-1) source |
| medium | verified against a strong secondary source, or partially verified against a primary one |
| low | unverified, inferred, assumed, conflicting, or only weak sources |
| unknown | public evidence is insufficient to establish this |

Narrative folders are created as the research tree discovers what this industry needs. The folder list is adapted to the industry, not fixed. Generated database views live in `databases/`.
